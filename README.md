# Aurelia Health

A modern digital healthcare platform designed to connect patients, doctors, hospital staff, and healthcare services through a unified web and mobile experience.

## Project Status

🚧 In active development

## Vision

Aurelia Health is being built as a premium, production-oriented healthcare platform that combines:

- Public hospital website
- Patient portal
- Staff management portal
- Appointment & queue management
- Cross-platform mobile application

## Planned Features

- Doctor discovery
- Online appointment booking
- Queue management
- Patient dashboard
- Doctor dashboard
- Receptionist portal
- Hospital administration
- Notifications
- Health library
